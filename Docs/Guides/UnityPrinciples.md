# Unity 개발 원칙 — 프로젝트 비의존

Unity 프로젝트라면 어디서나 같게 적용하는 방침만 모은다. 프로젝트마다 달라지는 값(네임스페이스 이름, 자산 경로, 도구 메뉴 이름, 아트 규칙)은 그 프로젝트의 `DEVELOPMENT.md`에 둔다.

> 원본: Pick&Shoot 저장소 `Docs/Guides/UnityPrinciples.md`. 프로젝트 의존 내용이 없으므로 다른 Unity 프로젝트에는 이 파일을 그대로 복사해 쓴다. 개선점이 생기면 원본에 반영한다.

---

## 1. 에디터 작업 자동화

- Unity Editor 수동 작업 대신 **일회성 자동화 스크립트**로 처리하고, **사용 후 스크립트는 삭제**한다(장기 도구만 보존).
- 장기 보존하는 플레이 모드 디버그 도구는 `Assets/Editor`의 **창 하나**에 모은다 — 씬 참조 없이 플레이 중인 오브젝트를 찾아 조작하므로 씬·빌드에 흔적을 남기지 않는다.
- 플레이 영상 자동 녹화 도구는 비교할 목적이 있는 동안만 보존하고, 목적이 끝나면 삭제 여부를 정한다. 영상은 git이 무시하는 폴더에 날짜와 HEAD 짧은 해시를 파일명에 넣어 남긴다. 절차는 [AutoPlayRecording.md](AutoPlayRecording.md).

## 2. 에디터를 열지 않는 사전 검증

Unity 번들 Roslyn 컴파일 검사 · 스텁 하니스로 로직 실행 · 스프라이트 시트 디코드는 [OfflineVerification.md](OfflineVerification.md). 그 위에 프로젝트의 UI 규칙을 얹어 화면을 합성해 비교하는 목업은 프로젝트별 문서로 둔다.

## 3. 데이터와 자산

- 데이터는 **전역 상수 클래스 또는 ScriptableObject(SO)**로 둔다. SO 자산이 SSOT이고, 구체적인 자산 경로·구조는 프로젝트 문서에 명시한다.
- 효과음 클립은 그것을 쓰는 시스템의 **직렬화 필드**(데이터 SO·프리팹·씬 컴포넌트)가 보관하고, 재생은 **한 곳**을 통해서만 한다.

## 4. 네임스페이스

프로젝트 전체에 **단일 네임스페이스** 하나를 쓴다. 폴더는 자유롭게 구성하되 네임스페이스와 매핑하지 않는다. 클래스명 자체가 기능을 드러내도록 명명하고, Unity 표준 타입과 이름이 충돌하는 심볼은 접두/접미로 회피한다. 단일 네임스페이스는 클래스명이 네임스페이스와 겹치는 문제도 함께 없앤다(예: 클래스 `Bullet`).

## 5. 프로젝트 폴더와 솔루션 이름

Unity는 프로젝트 폴더 이름으로 솔루션 파일(`.slnx`)을 만들고, 파일명에 쓸 수 없는 문자는 `_`로 바꾼다. 그래서 **모든 PC에서 프로젝트 폴더 이름을 저장소 이름과 같게** 두고, `.vscode/settings.json`의 `dotnet.defaultSolution`을 그 이름으로 고정한다 — 이 값을 PC마다 바꿔 커밋하지 않는다(`_`와 `-`가 오가는 핑퐁 커밋의 원인이었다). 폴더 이름이 다른 PC는 Unity와 VS Code를 닫고 폴더 이름을 바꾼 뒤 Unity Hub에 다시 등록하고, 옛 이름으로 남은 `.slnx`는 지운다.

## 6. 픽셀아트 임포트

픽셀아트 시트는 **PPU = 프로젝트의 텍셀 크기**(예: 16) · **Point 필터** · **무압축** · **격자 슬라이스**로 임포트하고, 스프라이트 이름은 `{시트}_{격자 인덱스}`로 둔다(예: `enemies_12`).

## 7. IMGUI로 그리는 픽셀 UI

- 해상도가 달라도 UI가 월드 스프라이트와 같은 규칙으로 보이게 하려면, **화면 세로 텍셀 수를 고정**한 기준 캔버스에 **정수 배율**로 배치하고 캔버스 전체를 화면 높이에 비례해 확대·축소한다. 종횡비는 가로로 보이는 범위만 바꾼다. 월드 카메라의 직교 크기를 기준 캔버스와 같은 텍셀 높이로 두면 어느 해상도에서든 월드와 UI가 같은 배율로 그려진다.
- 기준 해상도의 정수배가 아닌 해상도에서 텍셀 폭이 고르지 않은 것은 월드와 같은 조건으로 받아들인다.
- 다만 **타일을 이어 붙이는 조각**(9-slice 패널·가로 바)은 타일마다 네 변을 화면 픽셀 경계에 미리 맞춰 그린다 — IMGUI는 비정수 배율에서 쿼드의 위치와 크기를 따로 반올림해, 그대로 두면 이웃 타일 사이에 배경이 비치는 1px 틈이 생긴다(720p 등). 같은 이유로 게이지 채움은 `GUI.BeginGroup`으로 자르지 않고 프레임과 같은 자리에 놓은 타일을 폭만큼 잘라 그린다.
