# 유물 시스템

> [GDD](../GDD.md) §9의 상세 문서. 상위 개요·다른 시스템과의 관계는 GDD 본문 참조.

**기획안 (2026-10-02). 로드맵 1단계(스탯·커먼 유물·유물 보상 화면·유물/무기 교대)는 2026-10-03 구현 — §5의 확인할 것은 플레이 테스트 대기.** [GDD §3.4](../GDD.md#34-로그라이크-성장)의 **공통 축**을 유물로 구체화한 것이다 — 무기 축([Weapons](Weapons.md))과 짝을 이룬다. 웨이브 보상의 흐름(유물/무기 교대)은 GDD §3.4에 있고, 이 문서는 유물 자체만 다룬다. 구현 순서(§5)·용어는 2026-10-03에 정했고, 아직 정하지 않은 것은 §6에 모아 둔다.

**유물 = 웨이브 클리어 보상으로 획득하는, 런 안에서 영구히 지속되는 성장 요소.** 등급은 **커먼 · 레어 · 유니크** 셋이다 (2026-10-03). 지금 정의된 것은 커먼과 유니크이고 레어는 등급 세분화(§5 4단계) 때 채운다. 획득 순간 한 번 효과가 나는 **특별 보상(즉발형)**도 별도 카테고리가 아니라 유물의 일환으로 같은 풀에 둔다. UI 문구는 영문 대문자 글꼴에 맞춰 `COMMON`·`RARE`·`UNIQUE`.

---

## 1. 기본 방향

| 구분 | 획득 | 성격 |
|------|------|------|
| **커먼 유물** | 반복 획득 가능, 효과 중첩 | 주로 단순 수치 강화 — **지속적인 작은 성장** |
| **레어 유물** | 미정 | 커먼과 유니크 사이. 등급 세분화(§5 4단계) 때 정의 |
| **유니크 유물** | 런당 1회 | 특수 효과·플레이 방식 변화 — **지속적인 특수 효과** |
| **특별 보상 (즉발형)** | 즉발 | 획득 순간 한 번 발생, 이후 지속 없음 — **즉시 발생하는 큰 보상**. 별도 등급이 아니라 유물 풀에 섞여 나온다 (§4) |

유물 보상 화면에는 이 셋이 섞여 나온다 — 비율은 §6.

한 문장으로 — **무기를 획득하고 개조하면서 전투력을 구성하고, 커먼 유물로 기본 능력을 누적 강화하며, 유니크 유물로 특정 플레이 방식과 빌드를 만들어가는 웨이브 기반 액션 로그라이크.**

## 2. 커먼 유물

**설계 원칙**

- 반복 획득 가능. 같은 유물의 효과는 중첩된다 — 화력 코어 3개면 공격력 +15%.
- 기본적으로 단순한 수치 강화.
- 아래 **플레이어 스탯**에 더하는 것뿐이다. 새로운 플레이 규칙은 추가하지 않는다 — 스탯 자체가 아직 없는 것(공격력 배율·재생)은 유물에 앞서 스탯으로 먼저 둔다 (§5 1단계).

**현재 후보 (7종)** — SSOT는 자산 `Assets/Data/Relics` (RelicData). 카드 이름은 영문 대문자 글꼴에 맞춰 따로 짓고, 스탯 줄 라벨은 아래 카드 구성의 폭 제약 때문에 5글자 이하로 둔다.

| 유물 | 카드 이름 · 줄 라벨 | 효과 | 성장축 |
|------|------|------|-------|
| 화력 코어 | POWER CORE · DMG | 공격력 +10% | 공격 |
| 경량 프레임 | LIGHT FRAME · SPEED | 이동속도 +10% | 이동 |
| 강화 장갑 | ARMOR PLATE · MAX HP | 최대 체력 +3 | 생존 |
| 재생 장치 | REGEN UNIT · REGEN | 재생 +1 | 생존 |
| 자석 코어 | MAGNET CORE · RANGE | 탄환 회수 범위 +10% | 회수 |
| 회수 장치 | RETRIEVER · PULL | 탄환 회수 속도 +10% | 회수 |
| 충전 장치 | CAPACITOR · SKILL | 능력 리차지 속도 +10% | 능력 |

> 수치는 전부 튜닝 대상. 강화 장갑은 처음 +10이었으나 시작 체력 10·레벨 업 +1인 척도에 맞춰 +3으로 (2026-10-03). 퍼센트 유물은 처음 +5%였으나 정수 피해에서 +5%가 반올림에 묻혀(피해 5~10인 무기는 둘을 모아야 1이 오른다) 전부 +10%로 두고 밸런스 조정 때 다시 본다 (2026-10-03). 성장축 다섯(공격·이동·생존·회수·능력)은 §5의 검증 질문과 같다.

**플레이어 스탯** — 커먼 유물이 건드리는 값 7개. 유물은 이 값에 더할 뿐이고, 효과의 실제 적용은 각 스탯을 읽는 시스템(무기·이동·체력·회수·대시)이 한다. 구현(2026-10-03)은 플레이어의 `PlayerStats`가 보유 유물의 수정치 묶음(7칸 정수 — 배율은 퍼센트, 최대 체력·재생은 가산)을 전부 더한 총계를 들고, 기본값은 읽는 쪽의 직렬화 필드에 그대로 있다. 유니크 유물(§3)의 복합·패널티 효과도 같은 묶음(음수)으로 적는다.

| 스탯 | 지금 | 비고 |
|------|------|------|
| 공격력 배율 | 신설 (2026-10-03) | 모든 무기의 피해에 곱하는 플레이어 전역 배율. 무기 피해 = WeaponData 값 × 레벨 배율([Weapons §3](Weapons.md#3-무기-획득과-강화)) × 전역 배율 — 셋을 곱한 뒤 한 번만 반올림한다. 무기 카드의 DMG도 배율을 곱한 실제 값을 보인다. 유니크의 무기 집중·과충전·고정 포대도 같은 자리를 쓴다. |
| 이동속도 | 있음 | 가속·마찰은 그대로라 빨라진 만큼 최고 속도에 닿기까지 조금 더 걸린다. 대시 거리·시간은 바뀌지 않는다. |
| 최대 체력 | 있음 | 시작 10, 레벨 업마다 +1 ([GDD §3.3](../GDD.md#33-전투)). 유물로 오르면 오른 만큼 현재 체력도 더한다 — 강화 장갑을 얻는 순간 늘어난 칸이 차 있다. |
| 재생 | 신설 (2026-10-03) | 웨이브 중 일정 주기마다 체력을 회복하는 스탯. 웨이브 클리어 완충과 별개로 **웨이브 안에서 살아남는 데** 의의가 있다. 기본 0 — 유물 없이는 재생하지 않는다. **기본 주기 10초를 재생 수치로 나눈 간격마다 체력 1** — 재생 1은 10초마다, 3은 약 3.3초마다 (2026-10-03; 초당 소수 대신 정수 1 — 체력도 HUD도 정수라서). 체력이 가득 차면 타이머가 멈춰 피격 직후 바로 차지 않고, 회복 때 머리 위에 청록 `+1`이 레벨 업 문구처럼 떠오른다. "자연 치유" 대신 **재생**으로 용어를 통일한다 (2026-10-03). |
| 회수 범위 | 있음 | 자석 반경 ([GDD §3.2](../GDD.md#32-탄환-회수)). 발사 직후 "반경을 벗어났는가" 판정도 같은 반경. 흡수 거리·sweep 속도는 그대로. |
| 회수 속도 | 있음 | 자석이 탄환을 끌어오는 속도. |
| 능력 리차지 속도 | 있음 | **능력**은 지금 대시뿐이고([GDD §3.5](../GDD.md#35-대시)), 캐릭터에 따라 추가될 수 있다. 리차지 속도는 모든 능력의 쿨다운에 공통으로 적용한다 (2026-10-03) — 쿨다운을 배율로 나누며, 진행 중인 쿨다운은 건드리지 않는다. |

**카드 그림** — 유물 아이콘은 지금 쓰는 Kenney 팩에서 하나를 골라 **임시로 같은 그림을 색만 달리해** 쓴다 — Tiles 시트의 열쇠(`tiles_198`)의 몸통·음영 두 색을 유물별로 바꾼 사본 `Assets/Art/UI/relic_keys.png`(16×16 격자 7칸, 색은 전부 팩 팔레트 안). 처음엔 7종 전부 같은 열쇠였으나(2026-10-03) 카드에서 유물이 구별되지 않아 색을 나눴다 (2026-10-04). 색은 성장축을 따른다 — 공격 붉은색, 이동 흰색, 생존은 살구색(장갑)과 청록(재생 — 머리 위 재생 문구와 같은 색), 회수는 보라(범위)와 파랑(속도), 능력 주황. 유물별 그림은 고유 아트 때 ([Roadmap](../Roadmap.md)).

**카드** (2026-10-03) — 유물 보상 화면은 무기 카드 화면과 같은 3택이고 부제만 `CHOOSE A RELIC`. 카드는 무기 카드와 같은 패널·줄 구성 — 배지는 등급(`COMMON`, 회색), 전시 칸에 아이콘, 이름, 슬롯 줄 자리에 보유 수 `OWNED n → n+1`, 스탯 줄에는 그 유물이 건드리는 스탯만 `지금 총계 → 획득 뒤 총계`(`DMG 20% → 30%`) — 중첩이 카드에서 바로 읽힌다. 총계의 부호는 음수에만 붙인다 — `+`를 늘 붙이면 값 열이 넓어져 중첩이 쌓일 때 고정 폭 카드를 넘친다 (라벨 5글자 이하와 함께 99중첩까지 들어가는 것을 글꼴 지표로 확인, 넘치면 카드가 예외로 알린다). 후보는 7종 전부라 유물 화면은 건너뛰는 일이 없고, 리롤은 무기 화면과 같은 적립([Weapons §3](Weapons.md#3-무기-획득과-강화))을 나눠 쓴다. 자산에는 설명 문구(`description`, 영문 대문자 — `ALL WEAPON DAMAGE +10% PER STACK`)를 두었다 — 보상 화면 개편을 시도했다가 롤백해(2026-10-04, [Roadmap](../Roadmap.md) 진행 예정의 UI 개선) 아직 쓰는 UI는 없고, 유니크 유물(§3)의 조건 효과 설명이 들어갈 자리다.

**목적** — 커먼 유물만으로도 웨이브를 거치면서 캐릭터가 확실히 강해지는 느낌을 준다.

## 3. 유니크 유물

**설계 원칙**

- 같은 유물은 중복 획득 불가. 획득 후 런이 끝날 때까지 지속.
- 단순 수치 증가보다 **조건 / 시너지 / 행동 변화**를 중심으로 설계.
- 패널티와 보너스를 동시에 가지는 형태도 적극 활용.
- 목표: 획득했을 때 플레이 방식이나 빌드 방향이 달라진다.

**현재 아이디어**

| 유형 | 유물 | 효과 | 노리는 변화 |
|------|------|------|-----------|
| ① 빌드 연계형 | 무기 집중 | 현재 보유한 동일 무기의 개수가 많을수록 공격력 증가 | 특정 무기를 여러 자루 확보하는 빌드와 연계 |
| ② 회수 연계형 | 폭발성 탄약 | 탄환 획득 시 일정 확률로 폭발 발생 | 탄환 회수 자체를 공격 수단으로 |
| ③ 능력 연계형 | 과충전 | 능력 리차지 속도가 크게 증가하고, 능력 쿨다운 중 공격력이 증가 | 능력을 쓰고 다시 충전되는 동안 공격적으로 싸우는 플레이 유도 |
| ④ 행동 조건형 | 정지 재생 | 이동하지 않을 때 재생이 크게 증가 | 이동하며 싸울지, 위험을 감수하고 멈춰 회복할지 선택 |
| ⑤ 패널티 ↔ 보너스형 | 과충전 장치 | 공격력 크게 증가 / 이동속도 감소 | 단순한 강함이 아니라 플레이 방식 자체를 바꾼다 |
| | 경량화 | 이동속도 크게 증가 / 최대 체력 감소 | |
| | 고정 포대 | 이동하지 않을 때 공격력 크게 증가 / 이동 중 공격력 감소 | |

> 로드맵 3단계(§5)에서 행운 스탯과 함께 착수. ③ 과충전과 ⑤ 과충전 장치는 이름이 겹친다 (§6).

## 4. 특별 보상 (즉발형 유물)

별도의 보상 카테고리가 아니라 **유물의 일환**이다 — 유물 풀에 함께 들어가며, 획득 순간 효과가 한 번 발생하고 이후 지속되는 효과가 없다는 점만 다르다 (2026-10-03, 그전에는 별개 카테고리).

**두 갈래**

| 갈래 | 뜻 | 후보 |
|------|-----|------|
| 무작위 | 기존 시스템을 즉발로 호출한다 — 무엇이 나올지는 그 시스템의 무작위 풀이 정한다 | 리롤 +1 · 무기 추가 장착 · 무기 레벨업(보유 자루, [Weapons §3](Weapons.md#3-무기-획득과-강화)) · 무기 개조 획득 |
| 고정 풀 | 결과가 정해진 보상 | 현재 보유 무기 중 하나 복제 · 특정 레벨의 무기 획득 · 그 밖의 특별한 즉시 보상 |

구현은 로드맵 4단계(§5) — 무작위 갈래부터, 고정 풀은 그 뒤. 예외는 "무기 개조 획득" — 3단계 뒤 개조가 보상 순서에서 빠지면서 개조의 유일한 입구가 되므로 레어·유니크 유물로 먼저 넣는다 ([GDD §3.4](../GDD.md#34-로그라이크-성장)).

## 5. 구현 로드맵

네 단계로 넣고 단계마다 플레이로 확인한다 (2026-10-03). 웨이브 클리어 보상의 순서는 단계마다 바뀐다 ([GDD §3.4](../GDD.md#34-로그라이크-성장)) — 1단계 뒤 유물 → 무기 반복, 2단계 뒤 유물 → 무기 → 유물 → 무기 → 개조 반복, 3단계 뒤 다시 유물 → 무기 반복.

1. **스탯과 커먼 유물** — §2의 플레이어 스탯 7개를 한곳에 두고 없는 둘(공격력 배율·재생)을 신설한 뒤, 커먼 유물 7종과 유물 보상 화면(무기 카드 화면과 같은 3택), 유물/무기 교대를 넣는다. 끝나면 아래 **확인할 것**으로 판정한다. **구현 2026-10-03** — 확인할 것은 플레이 테스트 대기. 디버그 도구(`PickShoot/Debug Tools`)에서 유물을 골라 바로 얻을 수 있다.
2. **무기 개조** — 레벨업과 별개로 무기를 바꾸는 축. 아직 기획 전이라 기획부터 ([Roadmap](../Roadmap.md) 진행 예정). 보상 순서에 개조 자리가 생긴다 (다섯 주기).
3. **유니크 유물과 행운 스탯** — 유니크 유물(§3)과 함께 **행운**을 넣는다. 행운은 레벨 업 또는 웨이브 진행으로 오르는 플레이어 스탯이고, 높을수록 보상에 **강화된 무기**(획득 카드에 레벨이 붙은 무기)와 **더 높은 등급의 유물**이 나올 확률이 오른다 — 후반부로 갈수록 좋은 등급의 장비가 뜨게 하는 장치다. §2의 커먼 유물 7종이 올리는 스탯 밖이다. 보상 순서는 유물 → 무기로 돌아가고, 무기 개조는 고정 자리 대신 **레어·유니크 유물의 즉발형 보상**(§4 "무기 개조 획득")으로 들어온다 — 즉발형 유물(4단계) 중 이것만 앞당긴다.
4. **즉발형 유물과 유물 단계 세분화** — 특별 보상(§4)을 유물 풀에 섞고(무작위 갈래부터, 고정 풀은 그 뒤), 유물 등급을 더 나눈다(커먼·레어·유니크) — 행운이 고를 등급이 많아진다. 그 밖의 확장도 여기.

**확인할 것** (1단계 뒤)

- 유물을 얻는 것이 실제로 성장감이 있는가?
- 반복 중첩이 재미있는가?
- 공격/이동/생존/회수/능력 중 어떤 성장축이 가장 재미있는가?
- 무기와 유물의 선택이 서로 다른 판단을 요구하는가?
- 유물을 얻은 뒤 플레이 방식이 충분히 달라지는가?

미통과면 §2를 손본 뒤 다음 단계로 간다.

## 6. 미결 사항 (검토 중)

정해지면 본문으로 옮기고 여기서 지운다. 2026-10-03에 정한 것 — 능력의 범위(대시 + 추후 캐릭터 능력), "재생" 용어와 의의(웨이브 안 생존)와 단위(10초 ÷ 수치마다 1), 강화 장갑 +3, 퍼센트 유물 +10%, 유물/무기 고정 교대([GDD §3.4](../GDD.md#34-로그라이크-성장)), 구현 순서 네 단계(§5), 임시 아이콘 하나(열쇠)로 통일(2026-10-04에 색만 유물별로 나눔), 유물 화면의 리롤은 무기 화면과 같은 적립을 나눠 씀, 카드 구성(§2), 보유 무기·유물의 일시정지 화면 표시는 후속(§7).

- **레벨 업과의 분담** — 레벨 업도 최대 체력 +1을 준다 ([GDD §3.3](../GDD.md#33-전투)). 강화 장갑(+3)과 같은 축인데 둘을 그대로 둘지.
- **이름 겹침** — ③ 과충전과 ⑤ 과충전 장치. 하나는 이름을 바꾼다 (유니크 착수 때).
- **유물 화면 구성 비율** — 커먼/레어/유니크(와 그 안의 즉발형)를 섞는 비율. 유니크가 들어올 때.
