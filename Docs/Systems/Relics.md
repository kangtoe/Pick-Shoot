# 유물 시스템

> [GDD](../GDD.md) §9의 상세 문서 — 유물 자체(등급·커먼·유니크·즉발형·구현 로드맵·미결). [GDD §3.4](../GDD.md#34-로그라이크-성장) 공통 축의 구체화이며 무기 축([Weapons](Weapons.md))과 짝이다. 웨이브 보상의 순서(유물/무기 교대)는 GDD §3.4, 카드·타일의 꼴은 [Weapons §3](Weapons.md#3-무기-획득과-강화)·[PixelArtUI §4](PixelArtUI.md#4-아이템-타일과-배지), 결정의 날짜와 이유는 [Roadmap](../Roadmap.md).

기획 2026-10-02~03. 로드맵 1단계(스탯·커먼 유물·유물 보상 화면·유물/무기 교대)는 2026-10-03 구현 — §5의 확인할 것은 플레이 테스트 대기.

**유물 = 웨이브 클리어 보상으로 획득하는, 런 안에서 영구히 지속되는 성장 요소.** 등급은 **커먼 · 레어 · 유니크** (UI 문구 `COMMON`·`RARE`·`UNIQUE`). 지금 정의된 것은 커먼과 유니크이고 레어는 등급 세분화(§5 4단계) 때 채운다. 획득 순간 한 번 효과가 나는 **즉발형**도 별도 카테고리가 아니라 유물의 일환으로 같은 풀에 둔다.

---

## 1. 기본 방향

| 구분 | 획득 | 성격 |
|------|------|------|
| **커먼 유물** | 반복 획득, 효과 중첩 | 단순 수치 강화 — **지속적인 작은 성장** |
| **레어 유물** | 미정 | 커먼과 유니크 사이. 등급 세분화(§5 4단계) 때 정의 |
| **유니크 유물** | 런당 1회 | 특수 효과·플레이 방식 변화 — **지속적인 특수 효과** |
| **즉발형** | 즉발 | 획득 순간 한 번, 이후 지속 없음 — **즉시 발생하는 큰 보상**. 유물 풀에 섞여 나온다 (§4) |

유물 보상 화면에는 이들이 섞여 나온다 — 비율은 §6.

한 문장으로 — **무기를 획득하고 개조하면서 전투력을 구성하고, 커먼 유물로 기본 능력을 누적 강화하며, 유니크 유물로 특정 플레이 방식과 빌드를 만들어가는 웨이브 기반 액션 로그라이크.**

## 2. 커먼 유물

**설계 원칙**

- 반복 획득 가능, 같은 유물의 효과는 중첩 — 화력 코어 3개면 공격력 +30%.
- 아래 **플레이어 스탯**에 더하는 것뿐이다. 새 플레이 규칙은 추가하지 않는다.

**7종** — SSOT는 `Assets/Data/Relics`(RelicData). 카드 이름은 영문 대문자 글꼴에 맞춰 따로 짓고, 스탯 이름은 줄임말 대신 **읽어서 바로 아는 말**로 둔다 (2026-10-07) — 카드가 설명 없이 이 한 줄로 효과를 말한다. 폭 상한은 가장 긴 `PICKUP RANGE`·`PICKUP SPEED`.

| 유물 | 카드 이름 · 줄 라벨 | 효과 | 성장축 |
|------|------|------|-------|
| 화력 코어 | POWER CORE · GUN DAMAGE | 공격력 +10% | 공격 |
| 경량 프레임 | LIGHT FRAME · MOVE SPEED | 이동속도 +10% | 이동 |
| 강화 장갑 | ARMOR PLATE · MAX HP | 최대 체력 +3 | 생존 |
| 재생 장치 | REGEN UNIT · HP REGEN | 재생 +1 | 생존 |
| 자석 코어 | MAGNET CORE · PICKUP RANGE | 탄환 회수 범위 +10% | 회수 |
| 회수 장치 | RETRIEVER · PICKUP SPEED | 탄환 회수 속도 +10% | 회수 |
| 충전 장치 | CAPACITOR · RECHARGE | 능력 리차지 속도 +10% | 능력 |

> 수치는 튜닝 대상. 강화 장갑은 +10이었으나 시작 체력 10·레벨 업 +1 척도에 맞춰 +3으로, 퍼센트 유물은 +5%가 정수 피해의 반올림에 묻혀(피해 5~10인 무기는 둘을 모아야 1이 오른다) +10%로 (2026-10-03). 성장축 다섯(공격·이동·생존·회수·능력)은 §5의 검증 질문과 같다.

**플레이어 스탯** — 커먼 유물이 건드리는 값 7개와, 지금은 캐릭터만 건드리는 여덟째 최대 탄약(§6, [Characters §3](Characters.md#3-캐릭터-3종), 2026-10-13). 유물은 더할 뿐이고 적용은 각 스탯을 읽는 시스템(무기·이동·체력·회수·대시)이 한다. 구현(2026-10-03)은 플레이어의 `PlayerStats`가 수정치 묶음(8칸 정수 — 배율은 퍼센트, 최대 체력·재생·최대 탄약은 가산)의 총계 = 캐릭터 수정치 + 보유 유물 합을 들고, 기본값은 읽는 쪽의 직렬화 필드에 있다. 유니크 유물(§3)의 복합·패널티 효과도 같은 묶음(음수)으로 적는다.

| 스탯 | 비고 |
|------|------|
| 공격력 배율 | 신설 (2026-10-03). 모든 무기의 피해에 곱하는 전역 배율. 무기 피해 = (WeaponData 값 + 레벨 가산 × (레벨−1)) × 전역 배율 — 곱한 뒤 한 번만 반올림. 카드의 DMG도 배율을 곱한 실제 값. 유니크의 무기 집중·과충전·고정 포대도 같은 자리. |
| 이동속도 | 가속·마찰은 그대로라 빨라진 만큼 최고 속도에 닿기까지 조금 더 걸린다. 대시 거리·시간은 바뀌지 않는다. |
| 최대 체력 | 시작 10, 레벨 업마다 +1 ([GDD §3.3](../GDD.md#33-전투)). 유물로 오르면 오른 만큼 현재 체력도 더한다 — 늘어난 칸이 차 있다. |
| 재생 | 신설 (2026-10-03). 웨이브 중 주기마다 체력을 회복한다 — 웨이브 클리어 완충과 별개로 **웨이브 안에서 살아남는 데** 의의. 기본 0. **기본 주기 10초를 재생 수치로 나눈 간격마다 체력 1** — 재생 1은 10초마다, 3은 약 3.3초마다 (초당 소수 대신 정수 1 — 체력도 HUD도 정수). 가득 차면 타이머가 멈춰 피격 직후 바로 차지 않고, 회복 때 머리 위에 청록 `+1`. 용어는 "자연 치유" 대신 **재생**. |
| 회수 범위 | 자석 반경 ([GDD §3.2](../GDD.md#32-탄환-회수)). 발사 직후 "반경을 벗어났는가" 판정도 같은 반경. |
| 회수 속도 | 자석이 탄환을 끌어오는 속도. |
| 능력 리차지 속도 | **능력**은 스페이스 능력 — 캐릭터마다 하나다: 대시([GDD §3.5](../GDD.md#35-대시))·회수 펄스·충격파 ([Characters §2](Characters.md#2-능력-3종)). 모든 능력의 쿨다운을 배율로 나누며, 진행 중인 쿨다운은 건드리지 않는다. |

**아이콘** — Tiles 시트 열쇠(`tiles_198`)의 몸통·음영 두 색을 유물별로 바꾼 사본 `Assets/Art/UI/relic_keys.png`(16×16 격자 7칸, 팩 팔레트 안). 색은 성장축을 따른다 — 공격 붉은색, 이동 흰색, 생존 살구색(장갑)·청록(재생 — 머리 위 재생 문구와 같은 색), 회수 보라(범위)·파랑(속도), 능력 주황 (2026-10-04. 그전엔 7종 전부 같은 열쇠라 카드에서 구별되지 않았다). 유물별 그림은 고유 아트 때.

**카드** — 무기 카드 화면과 같은 3택, 부제 `CHOOSE A RELIC`, 리롤 적립을 무기 화면과 나눠 쓴다. 카드는 무기 카드와 같은 틀([Weapons §3](Weapons.md#3-무기-획득과-강화)) — 제목 노란 `NEW`(이미 가진 유물도 — 하나를 새로 얻는 카드이고 중첩은 전시 배지 `X n`이 말한다), 이름(두 낱말은 두 줄), 전시 타일(보유 수 + 1의 `X n`), 등급 줄 `COMMON`(레어·유니크의 글자색은 §5에서), **그 유물이 더하는 수정치 한 줄**(`GUN DAMAGE +10%` — 값은 초록, 양수에도 부호), 설명 줄. 수정치는 총계가 아니라 **1개분**이다 — 카드가 답할 것은 "이걸 고르면 무엇이 붙나"이고 총계는 일시정지 화면의 자리(§7). 보기 카드도 1개분이다 — 보유분 합은 같은 유물의 선택 카드와 값이 갈린다. 총계 표기(일시정지·디버그)는 음수에만 부호. 자산의 설명 문구(`description`)는 **스탯 줄이 못 하는 말이 있을 때만** 쓴다 — 커먼 7종은 비어 있고, 유니크(§3)의 조건 효과가 들어갈 자리. 후보는 7종 전부라 유물 화면은 건너뛰는 일이 없다.

**목적** — 커먼 유물만으로도 웨이브를 거치며 확실히 강해지는 느낌.

## 3. 유니크 유물

**설계 원칙**

- 같은 유물은 중복 획득 불가. 획득 후 런이 끝날 때까지 지속.
- 단순 수치 증가보다 **조건 / 시너지 / 행동 변화**를 중심으로 설계.
- 패널티와 보너스를 동시에 가지는 형태도 적극 활용.
- 목표: 획득했을 때 플레이 방식이나 빌드 방향이 달라진다.

**현재 아이디어**

| 유형 | 유물 | 효과 | 노리는 변화 |
|------|------|------|-----------|
| ① 빌드 연계형 | 무기 집중 | 현재 보유한 동일 무기의 개수가 많을수록 공격력 증가 | 특정 무기를 여러 자루 확보하는 빌드와 연계 |
| ② 회수 연계형 | 폭발성 탄약 | 탄환 획득 시 일정 확률로 폭발 발생 | 탄환 회수 자체를 공격 수단으로 |
| ③ 능력 연계형 | 과충전 | 능력 리차지 속도가 크게 증가하고, 능력 쿨다운 중 공격력이 증가 | 능력을 쓰고 다시 충전되는 동안 공격적으로 싸우는 플레이 유도 |
| ④ 행동 조건형 | 정지 재생 | 이동하지 않을 때 재생이 크게 증가 | 이동하며 싸울지, 위험을 감수하고 멈춰 회복할지 선택 |
| ⑤ 패널티 ↔ 보너스형 | 과충전 장치 | 공격력 크게 증가 / 이동속도 감소 | 단순한 강함이 아니라 플레이 방식 자체를 바꾼다 |
| | 경량화 | 이동속도 크게 증가 / 최대 체력 감소 | |
| | 고정 포대 | 이동하지 않을 때 공격력 크게 증가 / 이동 중 공격력 감소 | |

> 로드맵 3단계(§5)에서 행운 스탯과 함께 착수. ③ 과충전과 ⑤ 과충전 장치는 이름이 겹친다 (§6). [GDD §3.4](../GDD.md#34-로그라이크-성장)의 후보 공통 효과(회수 시 체력 회복·확률적 자동 회수 등)도 재료.

## 4. 특별 보상 (즉발형 유물)

별도의 보상 카테고리가 아니라 **유물의 일환**이다 — 유물 풀에 함께 들어가며, 획득 순간 효과가 한 번 발생하고 이후 지속되는 효과가 없다는 점만 다르다 (2026-10-03).

| 갈래 | 뜻 | 후보 |
|------|-----|------|
| 무작위 | 기존 시스템을 즉발로 호출한다 — 무엇이 나올지는 그 시스템의 무작위 풀이 정한다 | 리롤 +1 · 무기 추가 장착 · 무기 레벨업(보유 자루) · 무기 개조 획득 |
| 고정 풀 | 결과가 정해진 보상 | 현재 보유 무기 중 하나 복제 · 특정 레벨의 무기 획득 · 그 밖의 특별한 즉시 보상 |

구현은 로드맵 4단계(§5) — 무작위 갈래부터, 고정 풀은 그 뒤. "무기 개조 획득"을 개조의 두 번째 입구로 둘지는 [Mods §7](Mods.md#7-미결-사항--추후-검토).

## 5. 구현 로드맵

네 단계로 넣고 단계마다 플레이로 확인한다 (2026-10-03). 웨이브 클리어 보상의 순서는 유물 → 무기 반복으로 고정 ([GDD §3.4](../GDD.md#34-로그라이크-성장)).

1. **스탯과 커먼 유물** — 플레이어 스탯 7개를 한곳에 두고 없던 둘(공격력 배율·재생)을 신설, 커먼 유물 7종과 유물 보상 화면, 유물/무기 교대. **구현 2026-10-03** — 아래 확인할 것은 플레이 테스트 대기. 디버그 도구(`PickShoot/Debug Tools`)에서 유물을 바로 얻을 수 있다.
2. **무기 개조** — 레벨업과 별개로 무기를 바꾸는 축. 개조 4종이 무기 보상 화면에 섞여 나온다 ([Mods](Mods.md)). **구현 2026-10-10** — 확인할 것([Mods §6](Mods.md#6-구현-범위와-순서))은 플레이 테스트 대기.
3. **유니크 유물과 행운 스탯** — 유니크 유물(§3)과 함께 **행운**을 넣는다. 행운은 레벨 업 또는 웨이브 진행으로 오르는 플레이어 스탯이고, 높을수록 보상에 **강화된 무기**(획득 카드에 레벨이 붙은 무기)와 **더 높은 등급의 유물**이 나올 확률이 오른다 — 후반부로 갈수록 좋은 등급의 장비가 뜨게 하는 장치. 커먼 유물 7종이 올리는 스탯 밖이다.
4. **즉발형 유물과 유물 등급 세분화** — 특별 보상(§4)을 유물 풀에 섞고(무작위 갈래부터), 레어 등급을 채운다 — 행운이 고를 등급이 많아진다. 그 밖의 확장도 여기.

**확인할 것** (1단계 뒤)

- 유물을 얻는 것이 실제로 성장감이 있는가?
- 반복 중첩이 재미있는가?
- 공격/이동/생존/회수/능력 중 어떤 성장축이 가장 재미있는가?
- 무기와 유물의 선택이 서로 다른 판단을 요구하는가?
- 유물을 얻은 뒤 플레이 방식이 충분히 달라지는가?

미통과면 §2를 손본 뒤 다음 단계로 간다.

## 6. 미결 사항 (검토 중)

정해지면 본문으로 옮기고 여기서 지운다.

- **레벨 업과의 분담** — 레벨 업도 최대 체력 +1을 준다 ([GDD §3.3](../GDD.md#33-전투)). 강화 장갑(+3)과 같은 축인데 둘을 그대로 둘지.
- **이름 겹침** — ③ 과충전과 ⑤ 과충전 장치. 하나는 이름을 바꾼다 (유니크 착수 때).
- **유물 화면 구성 비율** — 커먼/레어/유니크(와 그 안의 즉발형)를 섞는 비율. 유니크가 들어올 때.
- **스탯 총계 표시** — 일시정지 화면에 스탯 총계(`GUN DAMAGE +30%` 등)를 둘지. 유물 플레이 테스트 뒤.
- **최대 탄약 스탯** — 캐릭터(HUNTER)가 쓰는 여덟째 플레이어 스탯 `MAX AMMO`(모든 자루 최대 탄약 +n, [Characters §5](Characters.md#5-데이터구현), 구현 2026-10-13). 커먼 유물(탄창 확장)로도 열지는 캐릭터 플레이 테스트 뒤.

## 7. 스코프 밖 / 후속

- **보유 무기·유물 표시** — 완료. 일시정지 화면과 보상 화면의 빌드 격자(유물은 종류별 `X n` 배지, 마우스를 올리면 보기 카드) ([PixelArtUI §4](PixelArtUI.md#4-아이템-타일과-배지)). 보상 화면의 유물 줄은 한 줄(12종)이 한계라 종류가 늘면 접는 방식을 정한다.
- **메타 성장**(러닝 간 언락)과 유물의 관계 — 미정.
