# Pick & Shoot — 개발 로드맵

MVP 검증을 최우선으로 하는 단계별 로드맵. 각 Phase는 **핵심 검증 질문**을 통과해야 다음 단계로 진행한다.

---

## Phase 1 — 핵심 프로토타입

> **검증**: "쏘고, 잔류하고, 줍고, 다시 쏘는" 사이클이 실제로 동작하는가?

### 작업

- [x] 플레이어 이동 (2D top-down)
- [x] 마우스 조준
- [x] 사격 (좌클릭)
- [x] 탄환 발사·비행·충돌
- [x] **영역 제한 아레나** (사각형, Brotato 방식)
- [x] **가장자리 벽 튕김** (핀볼식 반사)
- [x] 탄환 월드 잔류 (속도 감쇠 → 정지, 사라지지 않음)
- [x] 탄환 회수 (접근 시 자동)
- [x] 재장전 (회수한 탄환으로 즉시 사용 가능)
- [x] 최대 탄환 수 제한 (예: 6발)

### 통과 조건

- 탄환이 시각적으로 명확히 인지된다.
- 회수·재장전이 매끄럽게 이어진다.
- **"어? 이거 재밌을 것 같은데?"** 라는 감각이 생긴다.

### 산출물

- 빈 방 하나 + 벽 + 플레이어 + 탄환 시스템

---

## Phase 2 — 전투

> **검증**: 탄환 회수가 전투와 결합될 때 의미 있는 선택이 발생하는가?

### 작업

- [x] 기본 적 1종 (플레이어 추적)
- [x] 적 피격 / 사망 (HP·넉백·히트 플래시·명중 후 탄환 감속)
- [x] 플레이어 체력·피격 (무적 시간·데스 화면·R키 재시작)
- [x] 적 웨이브 (시간 기반, 지속시간 내 지속 스폰 · 종료 시 잔존 적 정리 · 무한 진행)
- [x] 적 스폰 전 경고 (붉은 "!" 텍스트 · blink)
- [x] 감각 튜닝 (벽 반사 강화·각도 제한·이펙트, 적/탄환 상호 분리, 탄환 자석 회수 Lerp, 저속 탄 충돌 무해화, 피격 시 화면 붉은 플래시, 탄환 2단 감속: sustain 후 급감속)
- [x] 피격 이펙트 (Hit 파문·Death 파티클 폭발·Pickup 파문·데미지 숫자: 적 흰색·플레이어 붉은색)
- [x] 탄환 부족 상태에서의 회피 플레이 성립 (자석 회수 완성으로 자연 성립)

### 통과 조건 ([Docs/GDD.md](GDD.md#5-mvp-테스트-기준) 참고)

- ① 탄환 잔류가 게임 플레이에 의미가 있는가
- ② 회수가 귀찮음보다 재미가 큰가 ← **최우선**
- ③ 탄환을 어디에 쏠지 고민하게 되는가
- ④ 탄환 부족 시 긴장감이 발생하는가
- ⑤ 공격 vs 회수의 선택이 발생하는가

**② 통과 실패 시**: 시스템 재설계 후 Phase 2 재검증.

## Phase 3 — 로그라이크 + 무기 시스템

> **검증**: 무기 조합·강화 선택이 서로 다른 플레이 스타일을 만드는가?

이 페이즈에서는 **무기 축만** 성장 대상으로 도입한다. 플레이어·탄환·회수 공통 축은 Phase 4 이후로 미룬다. 상세 규칙은 [Docs/Systems/Weapons.md](Systems/Weapons.md) 참조.

### 작업

- [x] **다중 무기 시스템** — 슬롯(시작 1, 최대 12), 무기별 독립 쿨다운·탄창, 발사 우선순위, 탄환 귀속·회수 (Weapons §1~§5)
- [x] **웨이브 클리어 → 업그레이드 선택 UI + 무기 획득·레벨업 풀** (Weapons §3)
  - 3택 선택 UI (웨이브 완료 시 게임 일시정지·선택 후 재개)
  - 획득: 새 슬롯에 무기 추가 (동일 무기 중복 허용, 최대 12까지, Lv.1로 시작)
  - 레벨업: 자루 단위 (공격력·발사속도·최대탄약 3항목 동시 상승)
  - 슬롯이 비어있을 경우 → 획득·레벨업 혼합 제시, 가득 찼을 경우 → 레벨업만 제시
- [x] **초기 무기 3종** — 권총(표준) / 산탄총(3발 동시) / 라이플(고관통) (Weapons §6)
- [ ] 웨이브 반복 → 난이도 상승
- [ ] 사망 시 러닝 종료 → 재시작

### 통과 조건

- 무기 획득/강화 선택이 **고민되는가**.
- 무기 조합이 서로 다른 **플레이 스타일**을 만드는가.
- 화력↑과 회수 부담↑의 **tradeoff**가 실제 긴장감을 만드는가.

## Phase 4 — 콘텐츠 확장

> **범위**: Phase 3 검증 완료 후 착수. 순서는 유동적.

Phase 3에서 무기 축만 도입한 성장 시스템을 **공통 축**으로 확장한다 ([GDD §3.4](GDD.md#34-로그라이크-성장)).

### 후보 작업

- **공통 성장 축** — 캐릭터·탄환·회수에 두루 적용되는 능력. 이동 속도·최대 체력·회수 범위·회수 속도, 탄환 잔류 시간·튕김 감쇠·튕김 시 피해·관통, 확률적 자동 회수·회수 시 부가 효과(체력 회복·이동속도 등)
- **폭발형 무기** (로켓런처 등) — 규칙은 [Weapons §7](Systems/Weapons.md#7-스코프-밖--백로그)
- 추가 무기 (기본 3종 외)
- **적 종류 다양화** — 상세는 [Docs/Systems/Enemies.md](Systems/Enemies.md).
  - **1차** — 기본 근접·빠른 근접·탱커 3종 (EnemyData SO + 이동 파라미터 분리). 웨이브별 점진 도입 골격 포함.
  - **2차** — 원거리·돌진 (전용 상태 머신, EnemyBullet 신설).
  - 백로그 — 방패·소환사·자폭 등.
- 보스전
- 맵/방 다양화 (프로시저럴 요소)
- 메타 성장 (러닝 간 유지되는 언락)
- 아트 패스 / 사운드 패스 — 1차로 Kenney Desert Shooter Pack(CC0) 스프라이트·효과음을 플레이스홀더로 적용 완료 (2026-09-16). 사격 반동·총구 화염 연출 추가 (2026-09-16). 업그레이드 카드 UI를 같은 팩의 Interface 시트(패널·비트맵 글꼴·아이콘)로 구성 (2026-09-16). 플레이어·적 이동 2프레임 걷기 애니메이션 적용 (2026-09-16). 인게임 HUD를 같은 Interface 시트로 구성 (2026-09-16) — 체력은 좌상단 패널에 칸 단위 핍, 플레이어 머리 위에는 비율 게이지; 무기 슬롯(탄약 핍)은 링 좌우에 따라 하단 양 끝 패널로 분리; 상단 중앙 웨이브 배너와 남은 시간 바. 카드 선택 화면 동안은 HUD를 숨김. 커서 중심 링에 전체 탄창 비율(자루별 비율 평균)을 표시 (2026-09-17). 고유 아트는 이후 과제.
- 튜토리얼
- **폴리싱 패스** — 핵심 루프·무기 검증이 끝난 뒤 "완성도" 마감. 세부 목록은 착수 시 확정.
  - **맵 꾸미기** — 현재의 빈 사각 아레나를 조금 더 있어 보이게. Kenney 팩 Tiles 시트로 바닥·가장자리 벽 타일 적용, 크레이트·바위·풀 등 장식 소품 배치, 배경 색·비네팅. 소품은 우선 순수 장식(충돌 없음)으로 두고, 튕김 장애물화 여부는 별도 판단. 맵/방 다양화(프로시저럴)와는 별개의 시각 과제.
  - 게임 필 — 카메라 흔들림·히트스톱, 적 스폰·사망 연출, 사격/피격/회수 이펙트 일관성 정리.
  - UI·연출 — 웨이브 시작/클리어 연출(백로그의 웨이브 UX와 통합), 업그레이드 카드·데스 화면 전환 애니메이션.
  - 사운드 — 볼륨 밸런스·믹싱, 배경음, 누락 효과음 보강.
