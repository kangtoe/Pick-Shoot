# Pick & Shoot (가제)

> **내가 쏜 총알을 다시 주워야 살아남는 로그라이크 슈팅 게임.**

## 개요

- **장르**: 로그라이크 액션 슈팅
- **플랫폼**: PC 우선
- **핵심 키워드**: 탄환 회수 / 자원 관리 / 전투 / 로그라이크

## 핵심 컨셉

일반적인 슈팅 게임처럼 탄환을 소비하고 재장전하는 것이 아니라, **발사한 탄환을 전장에서 직접 회수하여 다시 장전한다.**

```
Pick → Shoot → Pick → Shoot
```

탄환은 단순한 소모품이 아니라 **전장에 배치되는 자원**이며, 플레이어는 공격과 탄환 회수를 동시에 고려하며 전투한다.

## 핵심 재미

- 탄환을 어디에 쏠 것인가?
- 지금 탄환을 회수하러 가도 안전한가?
- 적을 빠르게 처치할 것인가, 탄환을 회수하기 좋은 위치에서 싸울 것인가?
- 어떤 업그레이드로 탄환 회수와 사격을 강화할 것인가?
